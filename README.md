# GuitarLogs 吉他练琴进度台

中文练琴记录与复盘工具。整段粘贴备忘录，自动识别日期、时长、模块和明确写出的BPM，保留原文，保护重复或有差异的日期，支持撤销导入。

此公开源代码版本不包含个人历史练琴日志。运行后可粘贴自己的备忘录，或导入自己的JSON备份。数据保存在浏览器本机，不会自动监听手机备忘录。

## 本地运行

无第三方依赖，需要Node.js。

```sh
npm test
npm run build
python3 -m http.server 8080 --directory dist
```

`index.html` 是界面，`note-parser.js` 负责本地解析，`history-data.js` 为可选初始数据，`dist/` 为构建产物。个人数据不纳入公开仓库，也不要提交浏览器备份或凭证。

只使用 `main` 分支；提交人名称按项目约定为 `sico`，每次提交用中文说明实际变更，后续修改需同步提交并推送。
